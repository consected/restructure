# `_db_columns`
## Database Column Type and Index Overrides

Override the inferred database column type for specific fields, mark them as array-type columns, or add database indexes.

> **Note:** `_db_columns` may be found within the `default:` options in older configurations. Although not recommended, the old configuration will continue to work.

```yaml
!defs(extra_options_top_level_db_columns_defs.yaml)
```
